O ZyraImages hospeda suas imagens e devolve um link direto que funciona em qualquer lugar. Nenhum endpoint exige API Key, token ou login, e o CORS está liberado.

<Info>URL base: `https://zyra-uploads.lovable.app/api/v1`</Info>
